# Third-party components

Livepanel orchestrates existing tools; it does not reimplement or rename them:

- Fastfetch: https://github.com/fastfetch-cli/fastfetch
- Starship: https://github.com/starship/starship (prompt inspired by the Tokyo Night preset)
- ANSIWeather: https://github.com/fcambus/ansiweather
- tmux: https://github.com/tmux/tmux
- playerctl: https://github.com/altdesktop/playerctl
- Rich: https://github.com/Textualize/rich
- psutil: https://github.com/giampaolo/psutil
- json5: https://github.com/dpranke/pyjson5
- Nerd Fonts: https://github.com/ryanoasis/nerd-fonts

Dependencies installed by your package manager or their official installers retain their licenses. The supplied custom font's notices are in `fonts/`. The LIVE PANEL SVG was created for this project and is covered by the project license.
