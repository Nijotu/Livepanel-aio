# Bundled font

`DroidCachyNerd-Regular.otf` is the author's supplied customized DroidSansMono Nerd Font, with a Cashy glyph added at U+F7000. Its family list includes `DroidSansMono Cachy Nerd Font`.

The original font license and Nerd Fonts license information accompany this file. The custom glyph was supplied by the project author; no additional ownership of third-party distro marks is claimed.

This font is separate from the project's MIT-licensed code. Keep its notices when redistributing it. The public default prompt also works with other Nerd Fonts.
